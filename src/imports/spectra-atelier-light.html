PHASE ONE · THREE AGENCIES, ONE ROOM

Before the beautiful, the honest.

Three senior agencies walk into the product and say what the deck won't. UI, UX, and engineering each file an independent critique — then we converge.

A
AGENCY A · VISUAL DIRECTION

The art direction is not arriving early enough.

— Maison Chroma, art direction studio

WHAT'S FORGETTABLE

The current system leans on dark-mode neon — the default "futuristic dashboard" dialect. It reads as competent, not iconic. No signature typeface moment, no editorial voice, no object you'd screenshot. The metrics live inside equally-weighted cards, which means nothing is beautiful.

WHAT TO CHANGE

Reposition Spectra as an imaging atelier, not a lab. Paper-white canvas, one saturated signature colour (Klein blue), oversized serif headlines with optical sizing, images treated as specimens with caption plates — not widgets.

B
AGENCY B · EXPERIENCE LOGIC

Side-by-side is a placeholder, not a product.

— North Field UX, product research agency

WHAT'S FORGETTABLE

Every parameter is visible at once — no progressive disclosure for quantization edge cases. The comparison is passive: two static images side-by-side. Users cannot inspect artifacts, zoom into regions, or sweep quality mentally. History is a spreadsheet, not a decision tool.

WHAT TO CHANGE

Make comparison the centerpiece interaction: a split-reveal slider with a lens mode for zooming into subbands and block artifacts. Collapse advanced quantization into an "Expert" disclosure. Turn history into a benchmark ledger where rows are reopenable runs.

C
AGENCY C · FRONTEND FEASIBILITY

Premium must survive the production build.

— Vector Works, engineering collective

WHAT'S FORGETTABLE

Heavy glow stacks and always-animated backgrounds create render cost on mid-range laptops where this audience actually works. The pipeline animation is decorative, not tied to real state. Chart-heavy results page is a canvas liability without virtualization.

WHAT TO CHANGE

Build it on Next.js + Tailwind + Radix + Motion. Pin glow to CSS variables, use container queries for workspace collapse, and hand image decode off to createImageBitmap with an OffscreenCanvas worker. Every "wow" is a real state transition, not a loop.

◆ AGENCY SYNTHESIS

Spectra is not a neon lab. It is a light-first imaging atelier — a specimen-card interface where serif typography carries the authority, Klein blue carries the emotion, and the split-reveal comparator carries the product. Every pixel must justify its cost on a 13-inch MacBook.

C · FRONTEND STACK

The boring stack, done seriously.

  1. Next.js 15 · App Router · TypeScriptServer Components for marketing surfaces, Client Components for the workspace and ledger.
  2. Tailwind CSS + CSS variablesDesign tokens declared once in globals.css — every component references var(--klein), never hardcoded.
  3. Radix UI primitivesSlider, Select, Tabs, Toast, Dialog, Tooltip, Toggle-Group — accessible by default, headless, style-yours.
  4. Motion (Framer)One orchestrated entry per route; pipeline transitions reflect real state, not loops. AnimatePresence for comparator mode switches.
  5. Recharts + custom SVGRecharts for line/bar; hand-authored SVG for sparkline + specimen art. Canvas only where layering demands it.
  6. ZustandThree slices: specimen, run, ledger. Persist ledger to IndexedDB via idb-keyval.
  7. Image decode in a workercreateImageBitmap + OffscreenCanvas → keep the main thread at 60fps while DWT runs.
  8. WCAG AAAll text ≥ 4.5:1 on paper. Focus rings mirror the Klein press shadow. Full keyboard map: J/K for runs, Space A/B, ⇧ lens.
D · WOW, IMPLEMENTED

Premium as a discipline, not a filter.

  1. Comparator dividerPure CSS clip-path: inset(0 0 0 X%) driven by pointer/keyboard — no canvas redraw, 60fps on integrated graphics.
  2. Lens modeOn Shift-hold, a 140px circular viewport samples a 4× region around the cursor. Implemented with a second image node + transform: scale(4).
  3. Pipeline pulseThe active stage uses a single @keyframes shadow-pulse; every other stage is static. Five non-animated nodes, one live node.
  4. ShimmerOnly appears on the progress bar during a real run. 1.6s linear, disabled for prefers-reduced-motion.
  5. Metric entryOn run-complete: staggered fade+rise (60ms · 4 rows) using Motion's staggerChildren. Once. Never looped.
  6. Empty statesEach panel has a serif-italic empty line: "Awaiting specimen." — never a generic "No data."
  7. SkeletonsPaper-shift skeletons: background-image: linear-gradient sliding across #EFEBDF. No full white flashes.
  8. ToastPaper card slides down from top-right, Klein left border, auto-dismiss 4s, dismiss on Esc. Plays once per run.
